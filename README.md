# FIPxielmon
***
## 介绍
***
一个依赖我的世界1.12.2重铸宝可梦开发的外部扩展口
咱简称其FIP

## 功能
***
- [x] 可添加宝可梦(模型,属性,材质,语言)
- [x] 自定义添加形态
- [ ] 可控野生宝可梦(AI,控制)
- [x] zip资源读取
- [x] 自定义精灵球
- [x] 自定义进化石
